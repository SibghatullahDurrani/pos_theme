## 1.0.0

- 5 themes (Corporate Blue, Midnight Pro, Emerald Fresh, Warm Terracotta, Monochrome Minimal), each light + dark.
- Tokens (`PosColors`, `PosShape`, `PosSpace`, `PosMotion`) and full Material 3 component theming.
- Responsive primitives: `PosWindow`, `PosResponsive`, `PosGrid`, `PosAdaptiveScaffold`, adaptive dialogs.
- Component library incl. data table, selects, toasts, charts and POS/restaurant widgets.
